HTTP-200 verified official upstream source URLs, SHA-256 digests, and archive

NOTE ON EMBEDDED NOTICE DISCREPANCY
-----------------------------------
Inside the immutable v2.7.2 Portable ZIP, OPEN_SOURCE_SOURCE_ACCESS.txt:
1. Lists qtwebengine-everywhere-src-6.12.0.tar.xz under .../qt/6.12/6.12.0/submodules/
   (which returns HTTP 404 upstream because Qt publishes QtPdf 6.12.0.140 /
   6.140.0.0 under qtwebengine/6.140/6.140.0/).
2. Does not separately list qtimageformats-everywhere-src-6.12.0.tar.xz for the
   bundled imageformats plugins (qicns.dll, qtga.dll, qtiff.dll, qwbmp.dll, qwebp.dll).

To ensure unambiguous LGPLv3 / GPLv3 Section 6(d) compliance for online binary
distribution alongside IR-CSP_v2.7.2_Windows_Portable.zip, ALL FOUR verified Qt
corresponding source archives are hosted directly as GitHub Release assets on v2.7.2.
